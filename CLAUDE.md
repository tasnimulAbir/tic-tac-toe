# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Two-player local Tic Tac Toe in plain HTML, CSS, and JavaScript. No build step, package manager, dependencies, linter, or tests.

## Running

Open `index.html` directly in a browser (`open index.html` on macOS). For a local server: `python3 -m http.server` and visit http://localhost:8000.

## Architecture

- `index.html` holds the static markup. The 9 board cells are `<button class="cell" data-index="0..8">` elements written out by hand, not generated by JS. `script.js` relies on `data-index` matching each cell's position in `querySelectorAll(".cell")`.
- `script.js` keeps all state in module-level variables: `board` (an array of 9 entries, each `"X"`, `"O"`, or `null`), `currentPlayer`, `gameOver`, and `scores` (keys `X`, `O`, `draw`).
  - `WIN_LINES` lists the 8 winning index triples.
  - `handleCellClick` places a mark, then checks for a win or a draw, or switches turns.
  - `endGame` updates the score and disables all cells.
  - `startRound` clears the board but keeps scores.
  - `resetScores` zeroes the scores and starts a new round.
  - Scores are kept in memory only and are lost on page reload.
- CSS classes set by JS:
  - `.x` / `.o` color each mark.
  - `.win` highlights the winning line.
  - `startRound` resets each cell with `cell.className = "cell"`, so any new per-cell class must be re-added there.
- `style.css` keeps colors in custom properties on `:root` (`--x`, `--o`, `--win`, etc.). Change colors there.
