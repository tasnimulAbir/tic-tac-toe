# Tic Tac Toe

A simple two-player Tic Tac Toe game built with plain HTML, CSS, and JavaScript.

## Features

- Two-player local play (X and O)
- Win and draw detection with the winning line highlighted
- Running scoreboard for X, O, and draws
- New round and reset scores buttons
- Responsive layout

## Play

Open `index.html` in any modern browser. No build step or dependencies required.
