# Tic Tac Toe

A simple two-player Tic Tac Toe game built with plain HTML, CSS, and JavaScript.

## Features

- Two-player local play (X and O)
- Win and draw detection with the winning line highlighted
- Stats dashboard: games played, win and draw rates, results split, current and best streak, average moves, a heatmap of winning squares, and recent games
- Stats saved in the browser (`localStorage`) so they survive a reload; Clear stats resets them
- Light and dark themes (follows the system, with a toggle)
- Responsive layout: side by side on desktop, stacked on phones

## Play

Open `index.html` in any modern browser. No build step or dependencies required.
